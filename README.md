# College Cover Page Maker 🎓📄

A lightweight, high-performance web tool to design and export professional A4 cover pages for college seminars, assignments, practical files, and project reports.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fneek-singh%2Fkdcg_tool.git)

---

## 🌟 Key Features

- **Multi-Subject Batch PDF**: Add multiple subjects with their respective teachers and download all covers in a single combined A4 PDF with 1-click.
- **Auto Academic Session Year**: Calculates and updates the academic session year (e.g., `Year 2026-27`) automatically based on the current date.
- **5 Professional Design Templates**:
  - Classic Floral
  - Modern Blue
  - Royal Gold
  - Dark Academic
  - Fresh Green
- **Customizable Courses & Semesters**: Pre-configured for B.A., M.A., B.COM., B.SC., and semesters 1 to 6 / annual exams.
- **High Resolution A4 Vector Print**: 300 DPI high-quality rendering using HTML5 Canvas & jsPDF.
- **Full SEO & PWA Ready**: Optimized with Open Graph tags, Schema.org JSON-LD, `sitemap.xml`, and `robots.txt`.

---

## 🚀 Deployment on Vercel

1. Push this repository to GitHub (`https://github.com/neek-singh/kdcg_tool.git`).
2. Go to [Vercel](https://vercel.com/) and click **"Add New..."** ➔ **"Project"**.
3. Import the `neek-singh/kdcg_tool` repository.
4. Keep the Framework Preset as **"Other"** (Root Directory `./`).
5. Click **"Deploy"**!

---

## 💻 Local Development

Simply open `index.html` in any modern web browser, or use a local static server:

```bash
# Using Python
python -m http.server 3000

# Using Node (npx)
npx serve .
```
