Seminar Cover Maker - A4 PDF
1) index.html ko browser (Chrome) me kholein.
2) Upar se Design template chunein (5 templates), phir text/rang/font/layout badlein.
3) 'A4 PDF Download' dabayein.

Files:
  index.html     - page ka structure
  css/style.css  - design
  js/script.js   - cover drawing + PDF logic
  js/logo.js     - college logo (base64)

Note: jsPDF library aur Google Fonts internet se load hote hain (pehli baar internet chahiye).

Naya template banana ho to js/script.js me TPL object me ek entry copy karke badal dein.
